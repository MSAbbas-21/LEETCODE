## 🧠 My Approach

For each problem, I try to understand:

1. What is the problem asking?
2. What is the simplest solution?
3. Can the solution be optimized?
4. What data structure or algorithm can help?
5. What is the time complexity?
6. What is the space complexity?
7. Can I explain the solution clearly?

The goal is not just to get **Accepted**, but to understand **why the solution works**.
